# Stellar Salvage Run

A colourful low-poly space flyer for Mac and Windows. You're a floating astronaut with a jetpack, salvaging EnergyStars through three zones until the Void Harvester wakes up.

**[Download the latest version](https://github.com/paardekam/stellar-salvage-run/releases/latest)** · [Game website](https://max.paardekam.nl/stellarsalvagerun/)

![Stellar Salvage Run](screenshot.webp)

## Download

| Platform | File | Notes |
|---|---|---|
| macOS 11+ (Apple chip & Intel) | `StellarSalvageRun.dmg` | Drag the game into Applications |
| Windows 10 & 11 (64-bit) | `StellarSalvageRun_Windows.zip` | Extract, then run `Stellar Salvage Run.exe` |

The game isn't signed by Apple or Microsoft yet, so the first launch needs one extra click:

- **Mac:** right-click the game in Applications, choose **Open**, then **Open** again. Still blocked? System Settings → Privacy & Security → **Open Anyway**.
- **Windows:** if "Windows protected your PC" appears, click **More info**, then **Run anyway**.

## How to play

| Keys | Action |
|---|---|
| A / D or ← / → | Move left and right |
| W / S or ↑ / ↓ | Climb and dive |
| Space | Boost (hold to charge a shot in the boss fight) |
| Esc | Pause |

Fly through the Asteroid Field, the Purple Nebula and the Abandoned Station. Each zone lasts a minute; clear it and pick an upgrade. Complete missions to earn tokens for new suits. Fly far enough and the Void Harvester shows up.
